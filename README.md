# ConsoleBank

Консольное приложение на C#, выполняющие банковские расчёты

## Как работает

1. Пользователь вводит сумму вклада.
2. Вводит срок в днях: `91`, `181` или `365`. При другом значении программа просит повторить ввод.
3. По сроку выбирается процент:

91 = 11.50%
181 = 11.75%
365 = 12.50%

4. Количество месяцев считается как `срок / 30`
5. Для каждого месяца: `доход = ставка / 100 / 12 * сумма`, после чего доход прибавляется к сумме
6. В конце выводятся общая надбавка и итоговая сумма на счету
